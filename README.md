## 🚀 Why LPU Fresher Guide?

LPU Fresher Guide focuses on one simple idea:

**Make essential information accessible to a fresher in seconds.**

The platform combines emergency support, important university links,
student services, contacts, and campus resources into one centralized
interface.
# 🎓 LPU Fresher Guide

> Find help without the confusion.

## 📌 About the Project

LPU Fresher Guide is a student-friendly web platform designed to help
new LPU students quickly find important campus resources, emergency
contacts, student services, and useful links in one place.

Instead of searching through multiple platforms, freshers can access
essential information from a single website.

## 🎯 Problem

New students often struggle to find:
- Emergency contacts
- Important LPU links
- Student services
- Campus resources
- Useful locations
- Information about whom to contact

## 💡 Our Solution

LPU Fresher Guide brings these resources together in one simple,
easy-to-use platform.

## ✨ Features

- 🚨 Emergency assistance and 112 call option
- 🔎 Search and filter contacts
- ⭐ Favourite important contacts
- 🔗 Quick access to LPU Touch
- 🔐 UMS Login access
- 🎓 Student Services
- 📝 Admissions information
- 🗺️ Google Maps / campus location access
- 👤 Student profile/student chip
- 📱 Responsive user interface
- 💾 LocalStorage for saved favourites
